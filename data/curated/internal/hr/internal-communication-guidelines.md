# Internal Communication Guidelines
Version: 1.2
Owner: People Operations

# Purpose

This document defines communication expectations for Northstar Solutions employees.

---

# Communication Principles

Employees should communicate with:

- clarity
- context
- respect
- accountability
- written traceability

---

# Slack Usage

Slack is appropriate for:

- quick questions
- operational coordination
- incident communication
- informal collaboration

Important decisions should not live only in Slack.

They must be captured in:

- project documentation
- ADRs
- customer notes
- ticket comments

---

# Channel Standards

Use public channels by default unless information is sensitive.

Examples:

- #engineering for technical discussion
- #ai-platform for AI systems
- #customer-delivery for customer work
- #security-incidents for security alerts

---

# Decision Documentation

Decisions must include:

- context
- options considered
- final decision
- owner
- follow-up actions

Architecture decisions should use the ADR template.

---

# Customer Communication

Customer-facing messages must be:

- accurate
- professional
- reviewed when high-risk
- free of internal-only details

---

# Incident Communication

During incidents:

- use designated incident channel
- avoid side-channel decisions
- keep updates concise
- document timeline

---

# Async Updates

Recommended format:

```txt
Status:
Risk:
Next step:
Owner:
ETA:
```

---

# Sensitive Information

Do not share in public channels:

- credentials
- customer secrets
- private customer data
- unreleased commercial terms
